HOW TO TEST (QUICK START)
═══════════════════════════════════════════════════════════════════════════════

SETUP:
  1. Start backend: cd backend && npm run start
  2. Start frontend: cd Frontend && npm run dev
  3. Open: http://localhost:5173

STEP 1 - ADMIN UPLOADS (2-3 min):
  1. Go to http://localhost:5173/admin/exams
  2. Click "Upload Exam" tab
  3. Select PDF file
  4. Enter:
     - Curriculum Course ID
     - Exam Year (e.g., 2024)
     - Exam Type (MID or FINAL)
  5. Click "Upload Exam"
  6. ✅ See success message

STEP 2 - ADMIN FINALIZES (2 min):
  1. Switch to "Review Questions" tab
  2. Enter Exam ID
  3. Review questions (optional: edit)
  4. Click "Finalize Exam"
  5. Confirm dialog
  6. ✅ Status changes to READY

STEP 3 - STUDENT PRACTICES (3-5 min):
  1. Log in as student
  2. Go to any course workspace
  3. Click "Previous Exams" tab in sidebar
  4. Modal opens with questions
  5. Select answer
  6. Click "Submit Answer"
  7. ✅ See feedback with explanation
  8. Click "Next Question" to continue

TOTAL TIME: ~10-15 minutes


API ENDPOINTS INVOLVED
═══════════════════════════════════════════════════════════════════════════════

ADMIN ENDPOINTS:
POST   /student/exams/admin/exams
       Upload exam PDF (multipart/form-data)
       Returns: Exam object with ID

GET    /student/exams/admin/exams/:id
       Get exam for review with all questions
       Returns: Exam + chunks array

PATCH  /student/exams/admin/exams/questions/:questionId
       Update question during review
       Returns: Updated question

POST   /student/exams/admin/exams/:id/finalize
       Mark exam as READY for students
       Returns: Updated exam


STUDENT ENDPOINTS:
GET    /student/exams/student/exams/questions
       Fetch practice questions for course
       Query params: curriculumCourseId, topic, questionType, limit
       Returns: Array of questions

POST   /student/exams/student/exams/evaluate
       Submit answer for evaluation
       Body: { questionId, answer }
       Returns: { isCorrect, correctAnswer, explanation, marks, maxMarks }

TROUBLESHOOTING QUICK REFERENCE
═══════════════════════════════════════════════════════════════════════════════

Issue: Modal doesn't open
  → Make sure PDF is open first (select from Upload)
  → Check browser console for errors
  → Refresh page if stuck

Issue: "No questions available"
  → Exam status must be READY (not EXTRACTED)
  → Check admin finalized the exam
  → Verify exam has questions in database

Issue: API errors
  → Backend down? Check terminal for "Server running on port 4000"
  → Network error? Check DevTools Network tab
  → Wrong courseId? Verify curriculumCourseId matches

Issue: PDF extraction fails
  → Check file is valid PDF
  → Check file size under 50MB
  → Check backend logs for error details

Issue: Questions don't structure properly
  → Check Gemini API key in .env
  → Check API quotas/rate limits
  → Check backend logs for LLM errors
