# StudAI – AI-Powered Learning Platform

## Project Description

StudAI is an AI-powered learning platform that helps Ethiopian university students study smarter using AI. It combines course materials, previous exams, AI tutoring, and personalized study tools into one platform.

## Problem

Students struggle with scattered learning resources, limited access to previous exams, and generic AI tools that do not understand Ethiopian university curricula. StudAI provides a centralized, curriculum-based learning experience tailored to local universities.

## Main Features

* User registration and authentication
* Course-based study workspace
* PDF upload and AI-powered summarization
* Context-aware AI chat for course materials
* Smart notes with auto-save
* Previous exam library
* AI-generated practice exams
* Flashcards, quizzes, and progress tracking

> **MVP Scope:** The first version supports **Addis Ababa Science and Technology University (AASTU)** and the **Software Engineering Department**, with a scalable architecture for future expansion to all Ethiopian universities.
