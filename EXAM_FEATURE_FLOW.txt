4. DATABASE SCHEMA OVERVIEW
═══════════════════════════════════════════════════════════════════════════════

TABLE: PastExam
┌─────────────────────────────────────────────┐
│ id              │ UUID (Primary Key)         │
│ year            │ INT (e.g., 2024)          │
│ type            │ ENUM (MID | FINAL)        │
│ fileUrl         │ STRING (Path to file)     │
│ status          │ ENUM (QUEUED | PROCESSING │
│                 │       | NEEDS_REVIEW      │
│                 │       | READY | FAILED)    │
│ curriculumCourseId │ UUID (FK)              │
│ uploadedBy      │ UUID (FK to Student)      │
│ processingError │ STRING (Error message)    │
│ createdAt       │ TIMESTAMP                 │
│ updatedAt       │ TIMESTAMP                 │
└─────────────────────────────────────────────┘

TABLE: PastExamChunk (Questions)
┌─────────────────────────────────────────────┐
│ id              │ UUID (Primary Key)         │
│ pastExamId      │ UUID (FK to PastExam)     │
│ topic           │ STRING (e.g., "Algebra")  │
│ question        │ STRING (Question text)    │
│ questionType    │ ENUM (TRUE_FALSE |        │
│                 │       MULTIPLE_CHOICE |   │
│                 │       SHORT_ANSWER |      │
│                 │       ESSAY)              │
│ options         │ JSON (Array of options)   │
│ correctAnswer   │ STRING (Correct answer)   │
│ explanation     │ STRING (Explanation)      │
│ marks           │ FLOAT (Points)            │
│ status          │ ENUM (EXTRACTED |         │
│                 │       NEEDS_REVIEW |      │
│                 │       VERIFIED |          │
│                 │       REJECTED)           │
│ createdAt       │ TIMESTAMP                 │
│ updatedAt       │ TIMESTAMP                 │
└─────────────────────────────────────────────┘

RELATIONSHIPS:
PastExam (1) ──← (many) PastExamChunk
  ├─ pastExam.id = pastExamChunk.pastExamId
  └─ When exam is deleted (onDelete: Cascade), all chunks deleted
