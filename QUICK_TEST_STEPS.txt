SETUP (DO ONCE)
───────────────────────────────────────────────────────────────────────────────
Terminal 1 - Backend:
  cd c:\Users\hp\StudAI\backend
  npm run start

Terminal 2 - Frontend:
  cd c:\Users\hp\StudAI\Frontend
  npm run dev

Browser: http://localhost:5173


STEP 1: ADMIN UPLOADS EXAM (2-3 min)
───────────────────────────────────────────────────────────────────────────────
1. Go to: http://localhost:5173/admin/exams
2. Tab: "Upload Exam"
3. Click blue upload area
4. Select any PDF file
5. Enter:
   - Curriculum Course ID: (any valid UUID from courses)
   - Exam Year: 2024
   - Exam Type: MID or FINAL
6. Click "Upload Exam"
7. ✅ See green success message

Check Backend: Should show processing logs in Terminal 1


STEP 2: ADMIN REVIEWS & FINALIZES (2 min)
───────────────────────────────────────────────────────────────────────────────
1. In Admin Dashboard, go to "Review Questions" tab
2. Enter Exam ID from Step 1
3. Questions should display
4. (Optional) Edit any question with the ✏️ icon
5. Click "Finalize Exam" button
6. Confirm dialog
7. ✅ Status changes to "READY"


STEP 3: STUDENT OPENS WORKSPACE (1 min)
───────────────────────────────────────────────────────────────────────────────
1. Log in as student account
2. Go to Courses page
3. Click on ANY course
4. Wait for workspace to load (see PDF in center)
5. Left sidebar should show tabs including "Previous Exams"


STEP 4: STUDENT CLICKS "PREVIOUS EXAMS" TAB (1 min)
───────────────────────────────────────────────────────────────────────────────
1. In left sidebar, click "Previous Exams" tab
2. ✅ Draggable modal appears on right
3. Modal title: "Previous Exams Viewer"
4. Shows:
   - Progress bar at top
   - Question counter (Question 1 of X)
   - Question text
   - Answer input area


STEP 5: STUDENT ANSWERS QUESTION (1-2 min)
───────────────────────────────────────────────────────────────────────────────
Depending on question type:

  TRUE/FALSE:
    Click "True" or "False" button
    Click "Submit Answer"

  MULTIPLE CHOICE:
    Click an option button
    Click "Submit Answer"

  SHORT ANSWER:
    Type in text box
    Click "Submit Answer"

  ESSAY:
    Type in text area
    Click "Submit Answer"

After submit:
  ✅ See result (✓ Correct / ✗ Incorrect)
  ✅ See correct answer if wrong
  ✅ See explanation
  ✅ See score


STEP 6: VERIFY & COMPLETE (1 min)
───────────────────────────────────────────────────────────────────────────────
1. Click "Next Question" to see more
2. Try different question types
3. Navigate with Previous/Next buttons
4. Progress bar should advance
5. ✅ No console errors (F12 > Console tab)
6. ✅ No backend errors (check Terminal 1)


TROUBLESHOOTING
───────────────────────────────────────────────────────────────────────────────
Problem: Modal doesn't open
  → Make sure a PDF is open first (select one from Upload)
  → Refresh page if still stuck

Problem: "No questions available"
  → Exam not finalized in Step 2
  → Double-check status is READY

Problem: API errors
  → Backend down? Check Terminal 1
  → Wrong curriculumCourseId? Get from Courses page

Problem: Questions don't load
  → Open DevTools (F12) > Network tab
  → Look for failed API calls
  → Check backend logs


SUCCESS INDICATORS
───────────────────────────────────────────────────────────────────────────────
✅ Admin can upload PDF
✅ Backend processes without errors
✅ Admin can review and finalize
✅ Student sees "Previous Exams" tab
✅ Modal opens when clicked
✅ Questions display
✅ Student can answer
✅ Feedback appears immediately
✅ No console errors
✅ No backend errors


TIME ESTIMATE: ~10-15 minutes total
