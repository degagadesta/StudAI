## 💡 Quick Tips

### Using the Theme
```tsx
// In any component:
import { useTheme } from '@/contexts/ThemeContext';

const { theme, setTheme, resolvedTheme } = useTheme();

// Current theme: theme ("light" | "dark" | "system")
// Actual applied: resolvedTheme ("light" | "dark")
```

### Common Patterns
```tsx
// Card
<div className="bg-surface border border-default rounded-xl p-4">

// Button
<button className="bg-accent hover-accent text-inverse">

// Input
<input className="bg-surface border border-default focus:ring-2 focus:ring-accent">

// Progress
<div className="h-2 bg-elevated rounded-full">
  <div className="h-full bg-accent" style={{ width: '60%' }} />
</div>
```
